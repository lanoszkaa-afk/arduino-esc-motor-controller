# Łącznik silnika ESC Arduino

## Funkcje
- Sterowanie silnikami w trybie PWM.
- Obsługa różnych typów regulatorów.
- Monitorowanie stanu silnika w czasie rzeczywistym.

## Wymagania sprzętowe
- Płytka Arduino (np. Arduino Uno).
- Zasilacz 5-12V w zależności od silników.
- Regulator ESC dostosowany do silników elektronicznych.

## Instalacja
1. Pobierz ten repozytorium:
   ```bash
   git clone https://github.com/lanoszkaa-afk/arduino-esc-motor-controller.git
   ```
2. Otwórz projekt w Arduino IDE.
3. Wgraj kod do płytki Arduino.

## Konfiguracja
- Upewnij się, że wybrane piny dla PWM są poprawnie skonfigurowane w kodzie. Można to zmienić w sekcji ustawień.

## Fixes
- Eliminowanie problemów z komunikacją między płytką a regulatorem ESC.
- Rozwiązywanie problemów z napięciem zasilania.

## Integracja z B4A
- Możliwość zdalnego sterowania przy pomocy B4A.
- Użycie protokołu Bluetooth do komunikacji.

## Testowanie
